# CodeAlpha_SecureCodingReview

## Overview

This project was completed as part of the CodeAlpha Cyber Security Internship.

The objective of this project was to perform a Secure Coding Review of a Bank Management System developed in C++. The review identifies security vulnerabilities, evaluates associated risks, and provides recommendations to improve application security.

## Application Features

- User Authentication
- Deposit Functionality
- Withdrawal Functionality
- Balance Inquiry
- Account Management

## Security Findings

1. Hardcoded Credentials
2. Lack of Account Lockout Mechanism
3. Missing Balance Validation
4. Negative Deposit Input Accepted
5. Weak Password Policy

## Recommendations

- Remove hardcoded credentials
- Implement secure password storage
- Enforce strong password policies
- Add account lockout mechanisms
- Validate all user inputs
- Implement Multi-Factor Authentication (MFA)
